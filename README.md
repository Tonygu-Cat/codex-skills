# codex-skills

一套给 OpenAI Codex 用的工作方式配置：3 个 Skill、1 份全局规则和 4 个钩子。它让 Codex 在长任务里持续推进、不跑偏、不过度防御，并能跨上下文压缩和跨会话可靠交接。

## 包含什么

| 部件 | 位置 | 解决的问题 | 何时生效 |
| --- | --- | --- | --- |
| task-operations | `task-operations/` | 做到一半停下、把失败当完成、让用户追问「下一步做什么」 | 改文件或多步执行的任务开始时直接加载；一次性问答不加载 |
| context-handoff | `context-handoff/` | 上下文压缩后丢方向；换会话要重新摸底 | 长任务、多阶段或可能发生压缩的任务 |
| leader | `leader/` | 一句话需求交给 agent 后跑偏、作弊达标、编造命令 | 要求「写个任务书 / goal / 拆任务」时 |
| 全局规则 | `examples/AGENTS.md` | 顺手扩范围、过度防御、整段读入大日志 | 每个任务 |
| 4 个钩子 | `examples/hooks.json` | 只靠提示词约束不住的环节 | 结束回复、压缩前后、用户发消息时 |

## 各部分能力

**task-operations：持续推进到验证完成**

- 检查 → 最小改动 → 验证 → 按证据诊断失败 → 修复重跑 → 完成审计，中间不等用户说「继续」。
- 一次尝试失败，目标仍是进行中；能换安全的路就自己换，不能就当场提出需要的授权。
- 只在 5 类真实边界暂停：缺系统权限、有实质影响的方案选择、只有用户知道的信息、不可逆或对外的操作、无法观察的外部状态。
- 每次结束回复都带「当前目标 / 下一步 / 用户操作」。默认不提交、不推送、不部署。

**context-handoff：跨压缩、跨会话不丢方向**

- 一份唯一的交接文档：方向卡（目标、完成条件、范围、非目标、已定决策）+ 当前状态 + 进行中工作 + 下一步及负责人。
- 每次压缩后，钩子把方向卡重新注入会话。
- 同一会话压缩满 10 次，或压缩后仍占窗口 25% 以上时，提醒在阶段收尾时交接；阈值在 `context-handoff/settings.json` 里配置。
- 人工确认交接：旧任务收尾、校验并封存交接，给出一行接班指令；用户新建任务粘贴即确认。接班任务只读核实旧任务已空闲、工作区与记录一致后接手。
- 配套脚本：结构校验、封存与任务定位入口、超大文档的安全瘦身。

**leader：一句想法变成能独立跑完的任务书**

- 先实测命令和基线，再一次性问完（最多 5 个问题），产出一份 ≤ 4000 字符、能直接粘进 `/goal` 的任务书。
- 任务书带可改路径白名单、防作弊条款、反向验证、断点续跑和按授权确定的交付终点。
- 管理者复跑书里的验收命令，再加 2–3 条执行者看不到的抽查，给 ≤ 5 行的验收报告。
- 会改运行态的任务，由一个没参与实现的独立会话审查改动（作者用的是 DeepSeek Harness，可以换成任意独立 reviewer）。

**全局规则（examples/AGENTS.md）**

范围与自主执行、必要配套的判据、简洁优先（新增校验或兜底要能指出具体来源，拿不准就让错误抛出）、精准修改、大文件与日志的读取方式、完成即停。

## 安装

脚本只依赖 Python 3 标准库。以下路径按默认的 `~/.codex` 写；设置了 `CODEX_HOME` 的话换成对应目录。

1. 把 `task-operations/`、`context-handoff/`、`leader/` 三个目录复制到 `~/.codex/skills/`。
2. 把 `examples/AGENTS.md` 的内容合并进 `~/.codex/AGENTS.md`（合并，不要覆盖已有内容）。不想用某一节就删掉那一节。
3. 把 `examples/hooks.json` 合并进 `~/.codex/hooks.json`。Windows 上如果 Python 命令不是 `python`，改成实际的命令或完整路径。下次启动 Codex 时按提示信任这些钩子；未信任的钩子不会运行。
4. 新开一个要改文件的任务，第一条回复里出现「任务运营：已加载 task-operations」就说明生效了。

## 运行测试

```bash
python -m unittest discover -s task-operations/tests
python -B -m unittest discover -s context-handoff/scripts -p "test_*.py"
```

当前分别是 20 项和 201 项，全部通过。

## 不做的事

- 不自动创建、归档或删除 Codex 任务；换代由用户粘贴接班指令确认。
- 不保证零压缩：压缩拦截只针对已封存的任务，宿主没执行钩子时没有这层保护。
- 不授予任何权限：提交、推送、合并、部署仍按用户授权。
- 钩子只检查回复的结构，不判断内容是否正确。
